1、把代码段

if (x > 0 && x < 10);
else
	printf("x is out of range.\n");
改写成下面这种形式：

if (____ || ____)
	printf("x is out of range.\n");
____应该怎么填？

解答：
x<=0 || x>=10

2、把代码段：

if (x > 0)
	printf("Test OK!\n");
else if (x <= 0 && y > 0)
	printf("Test OK!\n");
else
	printf("Test failed!\n");
改写成下面这种形式：

if (____ && ____)
	printf("Test failed!\n");
else
	printf("Test OK!\n");
____应该怎么填？

解答：
x<=0 && y<=0

3、有这样一段代码：

if (x > 1 && y != 1) {
	...
} else if (x < 1 && y != 1) {
	...
} else {
	...
}
要进入最后一个else，x和y需要满足条件____ || ____。这里应该怎么填？

解答：
x==1 || y ==1

4、以下哪一个if判断条件是多余的可以去掉？
这里所谓的“多余”是指，某种情况下如果本来应该打印Test OK!，
去掉这个多余条件后仍然打印Test OK!，
如果本来应该打印Test failed!，
去掉这个多余条件后仍然打印Test failed!。

if (x<3 && y>3)
	printf("Test OK!\n");
else if (x>=3 && y>=3)
	printf("Test OK!\n");
else if (z>3 && x>=3)
	printf("Test OK!\n");
else if (z<=3 && y>=3)
	printf("Test OK!\n");
else
	printf("Test failed!\n");

解答：
只需要删去第二个else if分支，即else if (x>=3 && y>=3) printf("Test OK!\n");即可
验证方法：删去条件后只需要看看当x≥3且y≥3时Test是否OK，请看1.4.3.c
使用布尔代数严谨推导：对于条件2、3、4,设A：x≥3，B：y≥3，C：z＞3。
合并条件2、3、4，想要Test OK，那么就相当于AB+AC+BC'=(ABC+AC)+(ABC'+BC')=AC+BC'
也就是说AB这个条件是可去的，即（x≥3 && y≥3）可删。
